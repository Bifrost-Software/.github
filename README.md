# Bifrost-Software

## English

Bifrost-Software builds and maintains software projects and open‑source tools. Based on the repositories currently available in this organization, the following repo is present:

- **.github**: Organization‑wide GitHub configuration and community standards shared across projects (for example, default issue/PR templates, contribution guidance, and other shared metadata).

## Nederlands

Bifrost-Software bouwt en onderhoudt softwareprojecten en open‑sourcetools. Op basis van de repositories die momenteel in deze organisatie beschikbaar zijn, is de volgende repo aanwezig:

- **.github**: Organisatiebrede GitHub‑configuratie en community‑standaarden die gedeeld worden over projecten (bijvoorbeeld standaard issue/PR‑templates, bijdrage‑richtlijnen en andere gedeelde metadata).
